# Teplica 2

Автоматизированная система управления мини-теплицей на базе Arduino. Проект следит за влажностью почвы, температурой, влажностью воздуха и уровнем воды, а также включает освещение и полив по заданному расписанию.

## Что умеет система

- Контролирует освещение по времени суток
- Поливает растения автоматически, если почва сухая и есть вода в резервуаре
- Проверяет уровень воды в баке
- Измеряет:
  - температуру воздуха
  - влажность воздуха
  - влажность почвы
- Отображает состояние датчиков на LCD 20x4
- Подаёт звуковой сигнал, если воды недостаточно
- Использует часы реального времени DS1307 для контроля расписания

## Основная логика

В `teplica2.ino` запускаются сервисы и устройства:

- `Lamp` — управление светом по времени
- `waterMotor` — автоматический полив в заданное время
- `LCD` — вывод данных с датчиков
- `Piezo` — звуковой сигнал при нехватке воды
- `RTC_Manager` — инициализация часов реального времени

## Компоненты проекта

### Датчики

- `Soil_Humidity` — датчик влажности почвы
- `Thermometer` / `Air_Humidity` — температура и влажность воздуха через DHT11
- `Bobber` — датчик уровня воды

### Устройства

- `Lamp` — светильник / лампа
- `waterMotor` — насос для полива
- `LCD` — дисплей
- `Piezo` — пьезодинамик

### Сервисы

- `RTC_Manager` — работа с часовым модулем DS1307
- `Service` — базовый класс с таймером
- `Device` — устройства, которые работают по расписанию
- `Sensor` — датчики, возвращающие значение

## Пины и подключение

Основные параметры из `teplica2.ino`:

- `lampPin = 11`
- `motorPin = 7`
- `soilHumidityPin = A1`
- `dhtPin = A3`
- `echoPin = A2`
- `trigPin = 8`
- `piezoPin = 6`
- `bobberPin = 9`

### Типовая схема

- DHT11 подключается к `A3`
- Датчик влажности почвы — `A1`
- Насос — `7`
- Лампа — `11`
- Пьезоизлучатель — `6`
- Датчик уровня воды — `9`
- LCD подключается по стандартной схеме LiquidCrystal (пины 10, 8, 5, 4, 3, 2)
- RTC DS1307 подключается по шине I2C (SDA/SCL)

## Параметры управления

Некоторые значения можно изменить прямо в исходниках:

- `minSoilHumidity = 500` — порог сухости почвы
- `motorPeriod = 5000` — период работы мотора
- `Lamp.hour_start = 6`, `hour_end = 22` — время работы света
- `waterMotor.hour = 8`, `minute = 30` — время полива

## Структура файлов

- `teplica2.ino` — главный файл Arduino
- `objects.ino` — создание объектов и запуск сервисов
- `all_objects.h` — подключение всех классов
- `Service.h` — базовый сервисный класс
- `Device.h` — базовый класс устройств
- `Sensor.h` — базовый класс датчиков
- `Lamp.h` — логика освещения
- `WaterMotor.h` — логика полива
- `SoilHumidity.h` — датчик влажности почвы
- `Thermometer.h` — DHT11 датчики температуры и влажности
- `Bobber.h` — датчик уровня воды
- `LCD.h` — вывод данных на экран
- `Piezo.h` — сигнализация
- `RTC.h` — работа с RTC
- `time.ino` — необязательный код синхронизации времени по NTP через Ethernet
- `Ethernet.h` — экспериментальный/дополнительный класс Ethernet

## Необходимые библиотеки

Для сборки проекта в Arduino IDE потребуются:

- `TimeLib`
- `DS1307RTC`
- `LiquidCrystal`
- `TroykaDHT`
- `Ethernet` / `Ethernet2` (если используется время по NTP)
